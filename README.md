# .github

Archivos por defecto de la comunidad para los repos públicos de [@ctala](https://github.com/ctala).

Hoy contiene solo `.github/FUNDING.yml`: GitHub lo aplica a todos los repos públicos de la cuenta
que no tengan uno propio, así que el botón de **Sponsor** aparece en todos sin copiar el archivo
repo por repo.

La licencia no se puede poner acá: va dentro de cada repo.
